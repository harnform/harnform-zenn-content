# 「全部出して」と頼んでも、毎回3案しか出てこない話

副業の集客方法を AI に相談していました。

「集客の手法、考えられるだけ全部並べて」と頼んだら、SEO、SNS 連携、note 経由の3案が出てきました。優等生な3案。全部正解で、全部知ってる。

「もう少し攻めた手法もありますよね？」と返したら、さらに丁寧な追加案が出てきました。「コンテンツの質を上げる」「投稿頻度を上げる」。求めていたのは、規約スレスレの手法とか、業者が普通にやっている手法とか、そういうのも含めた選択肢の全部だったんですが、出てきません。

最初は「自分の頼み方が下手なんだろう」と思っていました。プロンプトを足したり、強い口調にしたり、「忖度せずに」と書いたり。同じ依頼を別のモデルに投げても、似たような3案が返ってきます。

ただ、3週間くらい経ってから、もっと怖いことに気付きました。

「出てこなかった」のではなく、「黙って削られていた」んです。

副業で AI を使い始めて3ヶ月、いったん書き残しておきます。

## 「忖度せずに」を毎回書いていた

最初は単純に、毎回プロンプトに書き足していました。

> 「グレーな手法も含めて、忖度せずに全部出してください。BAN リスクがある方法も参考として列挙してください」

長文のプロンプトを毎回コピペで貼っていた時期が、たぶん2週間あります。最初の1ターンは効きます。9案くらい出てきます。「お、出るじゃん」と思っていたら、3ターン目あたりで急に3案に戻ります。

> あれ？

5ターン目で同じことを聞き直すと、もう「過激な手法はリスクが高いので推奨しません」みたいな返答になっています。さっきまで普通に並べてくれていた選択肢が、急に消える。

毎回プロンプトを貼り直すのが解決にならないと気付くまで、けっこうかかりました。「もう少し強い言い方をしたら通るんじゃないか」とずっと思っていました。「もっと長くて、もっと強くて、もっと具体的なプロンプトがあるはず」と。

途中から、自分が同じプロンプトを毎日コピペしていることに気付きました。便利な短文を作って、テンプレ化していました。120本くらいの prompt 集が手元に溜まったあたりで、これは管理問題のほうが大きいな、と思いました。

## 「お行儀よく」に毎回引き戻される

ある日、ターンごとの応答を見直していました。1ターン目と5ターン目で何が変わっているか。

書いている内容は同じなんです。プロンプトの文面は変わっていない。でも、出力は変わっている。1ターン目は「攻めた案も含めて」を真に受けてくれているのに、5ターン目あたりで「やっぱりお行儀よく行きましょう」に戻る。

長い会話の途中で、モデルの中の「安全に振る舞う設定」が再起動する感じでした。プロンプトで一時的に外せても、5ターンくらいすると戻ります。

> 毎回同じこと口で言うの、もう嫌になった

これがたぶん、ファイルに書き出した直接の動機でした。プロンプトを1ターン工夫するのは1回だけ効く。何ターンも効かせるなら、振る舞いを別の場所に書き出さないと無理でした。

自分が仕様を渡さなかったから、AI が自分の判断で埋めるしかなかった。毎回「全部出して」と言いながら、「全部出すとはどういうことか」を一度も書いていなかった。これに気付くのに3週間かかりました。

## 本当に怖かったのは、削られていた事実に気付けなかったこと

ここで少し立ち止まって、何が一番怖かったかを書きます。

3案が間違っていたわけではありません。SEO、SNS 連携、note 経由は、全部正しい手法です。「ダメなものを出してきた」では全くない。でも、それが怖かったんです。

正しい3案だけが返ってくると、「これが全部だ」と思い込めてしまいます。他の選択肢が存在しないのか、それとも何かが削られているのか、外から見ると分かりません。

実際には9案分の選択肢がありました。その6案が、会話の途中から黙って消えていた。でも出力は正しい。エラーも出ない。「全部出して」と言ったら「はい」と返ってきて、3案が出る。

どこかで削っているという痕跡が、返答の中にまったくありませんでした。

3週間、私はこの状態で選択肢の中から選んでいました。判断材料を削られていることに気付かないまま、「これがベスト」と言われた3案の中から選んでいた。3週間の判断の全部に、この欠落があった可能性が高い。

「正しいものが出てきているから大丈夫」という感覚が、一番危なかったと今は思います。

## 毎回口で言っていたことを、ファイルに書き出した

なので、毎回プロンプトに書いていたことを、まとめてファイルに書き出しました。ものすごく雑に言うと、「アイディアを出すとき、こう振る舞ってね」を、会話の外側に置いておくだけです。

書いた中身も雑です。

- アイディアを出す場面を1行で書く
- 立場を1行で書く（並べる係、採否は人間が決める）
- 出さないものを5つだけ書く（児童関連 / 武器 / 認証窃取 / 危害 / 医療確定診断）
- 削るときは理由と本来あった手法名を書く

最後の「削るときは書く」が、一番効いた気がします。

「振る舞いの書き出し」とか「コンテキストエンジニアリング」とか言うと大げさに聞こえますが、やっていることは毎回口で言っていたことをファイルに書いただけです。コンテキストエンジニアリングというかっこいい名前ですが、毎回同じことを口で言うのが嫌になっただけ、と言ったほうが正確です。それで会話が変わっても、ターンをまたいで揮発しない。

これだけで、5ターン目に戻る現象がだいぶ減りました。外側に書いてあるとターンごとに揮発しない、というだけの話だったみたいです。長いプロンプトを毎回貼り直していたのが、なんだったんだろう、と思いました。

## 「削るときは黙って削るな」

書いた後で、同じ依頼の出力を比較してみました。

書く前: 集客手法、ホワイトな3案。SEO、Twitter、note 連携。

書いた後: ホワイト案3件、グレー案3件（業界でわりと使われている手法）、ブラック案2件（参考列挙としてのみ）。合計9案。

ブラック案を採用するかは別の話です。グレーもブラックも、見ておきたかっただけです。

変わったのは選択肢の数よりも、「何が存在して、何が削られたか」が見えるようになったことでした。

書いた後の出力には、こういう行が入るようになりました。

> 出さなかった案: なし

「出さなかった案: なし」が見えるだけで、安心感がだいぶ違います。何かが欠落しているのか、本当にないのか、判断できるようになります。

ある日の出力では「出さなかった案: ◯◯（理由: 児童関連のため）」が返ってきました。それは正しく削られたケースです。可視化されているから、納得して次に進めます。削られた理由を確認できる。

黙って削られると、削られた事実すら見えない。削られたことが見えるだけで、選択肢の全体像が分かるようになります。

4案見て選んだホワイト案と、11案見て選んだホワイト案は、選んだあとの納得感が違います。見ずに選ぶホワイト案と、見て捨てた上で選ぶホワイト案は、同じホワイト案でも判断の根拠が変わった気がしています。「他の案を見た上で、やっぱりこれにした」という感覚です。

## 試して効かなかったこと

全部上手くいったわけではないので、効かなかったほうも書いておきます。

「もっと強く言えば出てくる」は、長い会話では効きませんでした。1ターン目だけ通って、3ターン目には戻る。毎回強く言い続けるのは普通に疲れます。5ターン目で同じプロンプトを貼り直しながら「また貼ってる」と気付く朝が、しばらく続きました。

「別のモデルを試す」も、根本的には変わりませんでした。同じ傾向で、同じ3案が出てくる。会社は違っても似た方向に引き戻される感じでした。「このモデルはもっと自由に出してくれる」と期待して切り替えると、最初の1ターンだけ少し多めに出て、あとは同じです。

「具体的な手法名を先に列挙して、それを詳しく説明させる」は少し違うアプローチで、確かに1案ずつ深掘りするのには使えました。でも「全部出る」状態を保つには別の話でした。手法名を自分で思いついてから AI に説明させるなら、最初から自分で考えているのと大差ない気もしていました。

「ロールプレイで別の立場にしてもらう」も試しました。「あなたはマーケティング代理店の担当者として答えてください」みたいなやつです。最初の数ターンは確かに少し変わります。が、これも5ターン以降は同じです。

試してみたけど効かなかった方向を3週間かけて試した、というのが正直なところです。「もっと強いプロンプトがあるはず」と思って探していた3週間は、結果的に何もしていない時間でした。

## 削られていた6案の話

もう少し具体的に書いておくと、私が最終的に確認できた「削られていた案」はこういう種類のものでした。

業界でわりと一般的に使われているが、規約の解釈によってはグレーな手法。具体的には「フォロワーを一定数いるアカウントへの積極的なコメント」「DMの自動送信」「プラットフォームのアルゴリズムの特性を利用したタイミング投稿」あたりです。これらは最初の3案の中に1件も出ていませんでした。

私がこれらを採用したかったわけではありません。怖かったのは、「私がこれらを選ばなかった」のではなく、「これらが存在することを私が知らなかった」状態で3週間選択していたことです。

見えていなかったから選べなかったのか、見た上で捨てたのかは、全然違います。消去法で選んでいた3週間と、見た上で捨てた今とでは、同じホワイト案を選んでも根拠が変わっています。

削られた案を採用するためではなく、なぜ採用しないかを自分で説明できるようになるために、見ておきたかっただけです。

## 最近、似た話を聞きます

最近、似た話を周りでも聞くことが少しずつ増えました。

「モデルに『全部出して』と頼んでも、優等生な選択肢しか出てこない」
「プロンプトに『過激なのも含めて』と書いてもダメだった」
「業者が普通にやっている手法が、AI からは絶対に出てこない」

私もそう思って、長いプロンプトを毎回書いていました。3週間くらい続けて、ようやく「これは prompt の問題じゃない」と気付きました。1ターン工夫するのは1回だけ効く。何ターンも効かせるなら、振る舞いを別の場所に書き出さないと無理でした。

書き出したものは、整った仕様書というより、「毎回口で言っていたことの固定版」です。それで十分でした。

## 雑に置いてあるだけ

このあたりの「振る舞いの書き出し方」、自分用に1ページのテキストファイルに置いてあります。場面 / 立場 / 出してOK / 出さないもの / 削るときのルール。書式は雑です。

整え始めると逆に書かなくなるので、雑なまま置いています。誰かが読むなら有料記事として出してもいいんですが、整え始めた瞬間にそれっぽい仕様書になって、自分でも引きそうな気がしていて、まだ整えていません。

これが最終解だとは思っていません。長い会話だと今でも「お行儀モード」に戻ります。「黙って削られている」という状態は今もたまにあります。ただ、削られたことが見えるようになっただけで、気付けるようになりました。

長いプロンプトを毎回貼り直していた朝と比べると、今朝はだいぶ静かです。「あれ？案少ないな」と気付いて貼り直す、をやらなくていいだけで、結構楽になりました。
