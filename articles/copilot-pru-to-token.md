# Copilot の課金が token 単位になるらしい、うちへの影響メモ

2026-06-01 から GitHub Copilot の課金体系が変わるらしい。

発表内容を読んだ限りでは、これまでの「premium request 1回 = 1 PRU（premium request unit）」という単位が廃止されて、「AI Credits（token ベース）」に移行する予定とのこと。Pro $10/月、Pro+ $39/月（$39 AI Credit 込み）、Business $19/user、Enterprise $39/user というプラン構成で、コード補完と Next Edit Suggestions は引き続き AI Credit を消費しない（無料維持）。

なお、2026-04-20 から新規 Pro/Pro+/Student のサインアップが一時停止されていて、Annual プランで契約済みのユーザーは期限満了まで旧 PRU 制が継続する、とも書いてあった。うちがどのプランに当たるかは確認が必要で、この記事を書いている時点では細部が読み切れていない。

以下は「うちではこう見ている」という個人メモなので、事実確認は公式ドキュメントを当たってほしい。

## PRU ってなんだったっけ

正直、PRU という単位はずっとよく分からなかった。

「premium request 1回 = 1 PRU」と言われても、1回がどれくらいのやり取りを指すのか、モデル差はどう効くのか、会話のターン数なのかリクエスト数なのか、今も正確には把握していない。請求画面に数字が出るけど、他の API 料金（Anthropic や OpenAI）と「合計でいくらかかっているか」を並べて見ることができなかった。

Copilot のコストは月定額の中に含まれているという感覚で運用していて、「月 300 回程度の planner/Bear 呼び出しを $0.04/回相当の体感で使っている」という雑な見積もりで動かしてきた。

ただ実際のところ、ログを見返すと Copilot 経由の呼び出しは直近 30 日で数件という状況で、体感コストの見積もりがまったく実態と合っていなかった可能性が高い。「月 300 回まで使えるから余裕がある」と思いながら、実際にはほとんど使っていなかった、という雑な運用だった。

> いや、なんで。

## token 単位になると何が変わるのか

AI Credits が token 単位になるということは、Anthropic API や OpenAI API と同じ「input K token いくら、output K token いくら」の体系に揃う、ということらしい。

うちが気になっているのはここで、token 単位になると Anthropic SDK の消費量と直接比較できるようになる。直近 30 日の Anthropic SDK（claude-code / agent 呼び出し含む）は、ログ上で sonnet 系 887 件、合計 55M token 超という数字が出ている。これと Copilot の消費量を同じ通貨で見れるようになるなら、「どこに投げるのが割安か」が判断しやすくなる。

PRU 時代はこの比較ができなかった。Anthropic は token、Copilot は PRU、という別々の通貨が並んでいて、換算レートも自明ではなかった。今後は同じスケールで見られるようになるらしい、という点は素直に助かりそうと思っている。

ただし、AI Credit の model 別の multiplier（モデルごとに何 token 分として計算するか）がどうなるかは、現時点の公式ドキュメントを読んだ限りではまだはっきり書いてなかった。Pro $10 プランに AI Credit が付くのか別売りなのかも、読んだ限りでは未確定に見える。このあたりは 6 月以降に実際の請求を見て確認するつもりでいる。

## コード補完が無料維持、というのはうちには関係が薄い

発表の中で「コード補完は AI Credit 消費なし」という点が強調されていて、IDE で補完だけ使っているユーザーには朗報なんだと思う。

ただ、うちのメイン用途は補完ではなく agent モード / planner 呼び出し / Bear（別 AI にケチをつけてもらう役）なので、補完の無料維持自体はあまり関係がない。影響が出るのはむしろ chat と agent モード側、ということになるらしい。

「補完は無料、でもチャットや agent は消費する」という構造が明確になるなら、うちの使い方では実質的に全部が課金対象になってくる可能性がある。これも 6 月以降の請求明細を見るまでは確信が持てない。

## 実消費の状況

ログを集計した範囲で書いておく。

直近 30 日の api_calls.jsonl を見ると、Copilot 経由（tool: copilot）の呼び出しは数件しかなかった。大半は `anthropic_sdk`（kabu の FMC ingest パイプライン）と `openrouter`（Bear 審査用）で、Copilot は思っていたより使えていなかった。

agent_tasks.jsonl 側では sonnet 887 件・55.2M token・$329 が Anthropic 系の主な消費になっている。Copilot 経由の呼び出し（copilot-gpt54）は 10 件・784K token・$0.40 程度。

つまり、現状の「Copilot での planner/Bear 活用」はほぼできていない状態で動いていた。PRU から token 移行の直接影響より、そもそも Copilot をうまく使えていないことのほうが問題だったかもしれない。

## 今後どう構えるか

正直まだ整理できていないが、いくつか気にしていること。

ひとつ、token 単位になると「1 回の planner 呼び出しが何 token 相当か」がログで追えるようになるはず。今は Copilot 経由の呼び出しでは token 数が記録されていないので、コスト比較ができていない。記録できるようになったら、Anthropic SDK 経由と Copilot 経由のどちらが割安かを実数で見たい。

もうひとつ、Pro+ $39 プランの「$39 AI Credit 込み」が何 token に相当するのかが分かると、月の上限感がつかめる。今の Anthropic SDK 消費（55M token）と比較すると、おそらく Copilot の枠だけでは全然足りない規模感なので、メインは Anthropic SDK のまま、Copilot は補助的に使う構成が続くんだろうと思っている。

ただ、この見通しが正しいかどうかは 6 月の請求が来てからでないと分からない。今は「token 単位になると計算しやすくなる」という方向で期待しつつ、実態はしばらく様子見という状態。

## まだ分からないこと

現時点で分からないまま置いてあることを書いておく。

- AI Credit の model 別 multiplier（gpt-5.4 と gpt-5-mini で何倍差になるか）
- Pro $10 プランに AI Credit が付くか、別途購入が必要か
- Annual 契約ユーザーの移行タイミングの詳細
- agent モードが 1 チャット = 1 リクエストとして課金されるのか、内部ツール呼び出し分も全部カウントされるのか

これらが分からないまま「影響はこうなる」と断定するのは難しいので、6 月になってから実数を見て判断するつもり。

最近、似た感想を周りでも聞くことが少しずつ増えた。

「PRU って結局何だったのか最後まで分からなかった」
「token 単位になったほうが比較しやすくていい」
「でも model 別の multiplier が分からないと計算できない」

同じ気持ち。抽象的な独自単位より、token 単位のほうが計算しやすいのは間違いないんだけど、細部がまだ出揃っていない。

使い始めてみないと分からないことがいくつかあって、まだ様子見が続く。
